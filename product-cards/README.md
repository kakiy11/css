# Product Cards — Next.js + Tailwind CSS

Готовая реализация практической работы «Стилизация компонента карточки товара с помощью Tailwind CSS».

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Проверка production-сборки:

```bash
npm run build
```

## Структура

- `app/globals.css` — подключение Tailwind через `@import "tailwindcss";`
- `app/page.tsx` — заголовок, адаптивная сетка карточек и кнопка коллекции
- `components/ProductCard.tsx` — переиспользуемый компонент карточки с `next/image`
- `data/products.ts` — типизированные данные четырёх товаров
- `public/images/` — четыре локальных SVG-иллюстрации товаров

## Адаптивность

Сетка использует `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` и `gap-5`:
- 375 px — 1 колонка;
- 768 px — 2 колонки;
- 1280 px — 4 колонки.

Кнопка «Смотреть всю коллекцию» занимает ширину контейнера на мобильном экране и имеет автоматическую ширину на больших экранах.

## Что проверять в DevTools

1. Запустите приложение и откройте DevTools (F12).
2. Включите режим устройства (Ctrl+Shift+M).
3. Установите ширину 375 px, 768 px и 1280 px.
4. Убедитесь, что сетка показывает соответственно 1, 2 и 4 карточки в ряд.
5. Наведите курсор на кнопки и проверьте плавное изменение оттенка фона.

> Скриншоты реального браузера в этот архив не включены: их следует снять после запуска приложения в DevTools на указанных ширинах.

## Краткий вывод (5–7 предложений)

Наиболее полезным оказался класс `grid`, потому что он позволяет организовать карточки в единую сетку. Классы `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` удобно переключают количество колонок в зависимости от ширины экрана. `gap-5` задаёт одинаковые промежутки между карточками без дополнительных CSS-правил. `rounded-3xl` и `rounded-2xl` помогают быстро настроить скругления карточки и области изображения. `object-contain` сохраняет пропорции иллюстрации и не обрезает товар. Классы `px-*`, `py-*` и `mt-*` позволяют точно управлять внутренними и внешними отступами. Наконец, `transition-colors` вместе с `hover:bg-blue-800` делает изменение цвета кнопки плавным.

## Ответы на вопросы для самопроверки

1. **Почему карточка — отдельный компонент?** Компонент можно повторно использовать для разных товаров, передавая данные через props, и не дублировать разметку.
2. **Какие классы задают сетку 1 → 2 → 4?** `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`.
3. **Чем отличаются `object-contain` и `object-cover`?** `contain` показывает изображение целиком, сохраняя пропорции; `cover` заполняет область и может обрезать края. Для предмета на однотонной подложке подходит `object-contain`.
4. **Как задать произвольное скругление?** Например, `rounded-[20px]`.
5. **Зачем `key` в `.map()`?** React использует стабильный ключ, чтобы различать элементы списка при обновлениях; здесь используется `product.id`.
6. **Как проверить адаптивность без просмотра кода?** Открыть DevTools, включить режим устройства и проверить ширины 375, 768 и 1280 px.
7. **Что будет без `@import "tailwindcss";`?** Tailwind CSS не подключится штатным способом, и его утилитарные классы не будут применяться как ожидается.
